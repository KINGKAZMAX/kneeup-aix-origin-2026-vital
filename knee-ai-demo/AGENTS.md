# AIR-FLOW-Knee+ — 项目协作规则

## 先读取

开始工作前依次读：`CODEX_HANDOFF.md`、`docs/AI_INTEGRATION_SPEC.md`、`README.md`、`HARDWARE_PROTOCOL.md`、`docs/HANDOFF_VERIFICATION.md`。产品定位原文在 `docs/reference/PROJECT_SOURCE_EXTRACT.md`。

## 本轮目标

在现有 HTML/CSS/JavaScript 的 USB 只读观察页面中接入**真实模型调用的 AI 观察与建议**，展示依据、限制、来源与历史记录。保留品牌、视觉和既有主流程，不另起一个空项目，不迁移框架，不改成通用健康聊天机器人。

用户此前报告距路演约 15 小时；这是当时的剩余时间，不是现在重新开始计时。按最小可演示闭环推进，不再次询问已经提供的背景。

项目仍定位为 AI Adaptive Mobility Assist System / Active Aging / Mobility Longevity / Assist, not replace。本轮的只读 AI 观察层只是阶段性交付，不能代替原文的长期主动助力定位，也不能声称已经完成 AI 物理闭环。

## 硬边界

- 现有唯一已确认的传感输入为 A0 单路肌电；A5 是控制器输出，不是实际泵状态、压力或力反馈。
- 旧固件只输出一行一个滤波数字；66.0 是源码参考阈值，不是旧协议回读值。可选 v1 才上报 raw / threshold / a5 / seq / 时间等。
- 不把肌电数值写成肌力百分比；不把 A5 翻译成实际充气、泄压或助力；不从现有输入推断上楼、坡度、疲劳、左右腿力量或临床效果。
- 原程序包含 delay(4000) 与 delay(1000)，不是持续 500 Hz 肌电。不要为平滑曲线改固件时序或滤波；状态帧重复 seq 不能算新样本。
- 本轮不添加串口写入、自动改变阈值、启动/停止气泵、阀门控制或远程急停。AI 生成文本不得变成设备命令。
- 停止记录、断开 USB、关闭网页均不是已经核验的物理急停或泄压。不得以只读网页为理由省略台架检查。
- 所有协议、页面和模型测试使用的 synthetic/mock/replay 数据都必须显式标记；失败不得悄悄切成假实测或假 AI。
- AI 不可用时显示“规则解释 / AI 未连接”；不得显示“AI 已分析”。模拟数据上的真实模型输出必须同时标注“真实模型 + 合成输入”。
- 生理数据默认不外发。首次启用外部模型应由操作者确认发送字段及模型服务；不发送姓名、联系方式、视频或全部健康历史。
- 不从其他目录寻找凭证。密钥只从本项目本机服务端环境读取，不放浏览器、URL、localStorage、前端源码或日志，不提交 .env。
- 当前 serve.py 会从项目根目录提供文件；新增密钥前必须改为显式静态资源白名单并阻止目录遍历、目录列表、点文件/环境文件/私有日志下载，绑定回环地址，验证写请求来源。
- 只在该项目目录内改文件；保留用户变更，不覆盖其他版本，不清理用户目录，不自动烧录固件。

## 实现习惯

先跑基线测试，再增量开发。优先新增轻量模块并复用 `window.AirflowLive.device`；不要再创建第二个串口实例。页面切换后监听器只注册一次。

按 `docs/AI_INTEGRATION_SPEC.md` 校验输入、输出和异步结果归属；API 缺失时继续完成适配器与测试，列出真实调用未验证，不用伪结果填空。不能用一段提示词或 JSON 格式约定代替程序校验。

模型供应商、base URL、model、API key 尚未提供。读取本项目明确配置，不猜测型号、收费权限或可用端点；需要时查所选服务的官方文档。提供未填写的环境变量模板，不假定 Codex 的登录就是应用后端的模型凭证。

避免新增 React/Vite/数据库/云服务/多 Agent 编排等非必要依赖。若确需依赖，记录原因和启动影响。功能交付包含异常态、加载态、来源标签、导出与测试，不只交一张新界面。

## 基线命令

```bash
python3 serve.py --no-browser
node --test tests/protocol.test.cjs
python3 tests/native_firmware_test.py
# 需要 Playwright + Chromium；运行条件见原 TEST_REPORT.md
python3 tests/browser_smoke.py
```

启动网页：`http://localhost:8000/?view=hardware`。首次实物联调先由硬件负责人断开气泵外部电源并确认设备状态。
