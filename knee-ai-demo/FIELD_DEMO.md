# 膝望现场演示 · 两分钟主流程

本稿对应当前共享会话版本。软件可以排练；真实模型目前未配置，USB、真实摄像头与物理响应须另行验收。人物“志远，62 岁”为演示人物。

## 上场前准备

1. 运行 `python3 serve.py`，电脑 Chrome／Edge 打开 [首页](http://localhost:8000/)。采集直达 [硬件观察页](http://localhost:8000/?view=hardware)。
2. 检查 `vision-vendor/` 本地资源完整，点击“检查本地动作模型”。选择摄像头或一段队伍自己的本地动作视频，核对观察侧；视频必须标注回放。
3. 真实 USB 由硬件负责人先核对板型、固件和台架状态。本轮只见系统枚举 Espressif `303a:1001` 线索，没有打开串口或烧录，不能直接当作 UNO 使用。连接前先断开气泵外部电源，核实实际停止与泄压方式。
4. 只有实际收到 USB 数据后才称“串口输入”。软件彩排可点击“显式开启合成演示”，全程保留“合成输入 · 非实测”。
5. 真实 AI 配置按 [README](README.md) 完成后先核对服务与字段并授权，不在计时中临时找密钥。当前未配置时使用明确标注的规则解释，并在讲稿中说“真实模型调用待验收”。
6. 先完成三轮计时彩排并导出每轮会话。只有真实通过的输入与执行镜头才能作为现场联动证据；台架镜头未通过就改为标注清楚的独立实物展示。

## 两分钟主演示

| 秒数 | 操作 | 现场证据与口径 |
|---|---|---|
| 0–20 | 进入已准备好的采集页，开始网页记录 | “这是本次会话和实际来源。开始记录只影响网页。” |
| 20–40 | 队员完成受控动作 | 肌电值与摄像头／回放角度独立标记；左／右侧可见，遮挡时未测得 |
| 40–55 | 展示已核验的台架响应或独立实物 | A5 是控制器电平；没有压力反馈就不显示实际压力结论 |
| 55–85 | 主动结束并标注，立即分析 | 提前完成授权；结束后立即点击，必须满足最后样本年龄 ≤7 秒。展开模型观察、依据、局限与复核问题 |
| 85–105 | 切到专业端，查看同一编号 | 展开固定输入或定位事件；选择正确会话，填写备注 |
| 105–120 | 点击复核，回到用户端 | 同一记录出现明确复核结果；结束前导出完整 JSON |

建议讲述：“这里的主动结束来自操作者标注，系统不会猜原因。AI 只解释允许发送的肌电摘要和固定事件，摄像头画面与角度都留在本机。专业端查看的是这台电脑中的同一份记录。”

## 当天故障切换

- **USB 不通：**明确切换为软件合成演示，另展示实物。不要将两者说成已联动。
- **摄像头不可用：**使用本地视频，保留“回放”标签与媒体时间；或将动作观察保持未测得。
- **模型无配置、超时或校验失败：**说“当前为规则解释 / AI 未连接”，继续展示会话与人工复核。不能把预写文字标成真实 AI 返回。
- **最后样本超过 7 秒：**重新开始一份会话采足至少 5 点／4 秒，再及时分析；不把旧会话补成新数据。
- **会话刷新丢失：**使用事先导出的完整 JSON 作为离线证据展示。本版没有 JSON 导入或云端恢复功能。
- **物理响应未验收：**用明确标注的独立实物镜头，省略“实测已助力”的表述。
