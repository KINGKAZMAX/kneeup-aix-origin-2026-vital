# 膝望 · AIR-FLOW Knee+ 路演交付版

**继续走自己想走的路。** 膝望是一套面向 60–75 岁、仍能自主行动人群的气动行动辅助原型，将护膝、传感记录与 AI 观察连接起来。日常行动是入口，专业服务是延伸，徒步是希望保留的生活目标。页面中的“志远，62 岁”是演示人物，非真实个案。

本版按用户确认的碳黑 × 钴蓝配色规范统一界面；`tokens.css` 为配套令牌。规范唯一正本为工作区 `项目二/design/UIUX配色规范-碳黑钴蓝-v1.md`，随交付附有“品牌规范”副本。

本版复用 USB + AI 交接包，接通同一浏览器内的肌电采集、摄像头观察、人工事件、AI 依据和专业复核。**当前真实 AI 未配置，真实 USB 与物理响应未验收。** 不把软件测试、合成输入或模型适配代码描述成实物成功。现场步骤见 [FIELD_DEMO.md](FIELD_DEMO.md)，验证范围见 [TEST_REPORT.md](TEST_REPORT.md)。

本轮已完成 55 项 Node、23 项后端及 6 项主机固件替身检查，并在本机浏览器完成三轮基础软件流程（34.270／28.294／51.350 秒）。浏览器输入为合成肌电与本地约 27 秒视频回放，外部模型未配置；这不是含真实 AI 和台架响应的完整实物彩排。专业端与用户端会话及复核结果一致。本地 MediaPipe 加载和回放运行成功，近景缺少完整髋／膝／踝时角度保持 null。导出结构与来源经过 Node 测试，浏览器已点击导出按钮，但下载文件落盘未独立验收。

## 启动与入口

需要 Python 3.9+，建议使用电脑 Chrome 或 Edge。应用无须 npm，也无运行时第三方 Python 依赖；本地视觉模型及其运行资源已随包提供，约 25 MB。

```bash
python3 serve.py
```

Windows 可用 `py -3 serve.py`。打开 [日常行动首页](http://localhost:8000/)，或直达 [采集与观察](http://localhost:8000/?view=hardware)。`start.command` / `start.bat` 也可启动。端口被占用时运行 `python3 serve.py --port 8001`，使用相应端口；`--no-browser` 仅启动服务。

服务只监听当前电脑的回环地址。USB 插在这台电脑，同机角色共享当前页面内存；另一台电脑、另一个标签页或手机不会自动收到记录。请通过本地服务访问，不要直接双击 HTML，也不要在嵌入预览中选择 USB。

## 一次完整记录

1. 打开“开始记录”。任务来源固定为团队路演脚本，由队员演示受控动作，不是 AI 生成的个体训练处方。
2. 输入选择其一：现场 USB 接入由硬件负责人按下节核验；软件排练可明确点击“显式开启合成演示”。来源始终可见，失败不会自动切成模拟。
3. 收到有效数据后点击“开始记录”。从此刻起的新采样进入统一会话。没有有效肌电来源时，仍可单独查看摄像头画面，但不能声称已建立完整采集会话。
4. 需要动作观察时，检查本地动作模型，再开启摄像头或选择本地视频。选择观察侧，让髋、膝、踝完整出现在侧面画面中。
5. 记录足够数据后，点击“主动结束并标注”。它添加人工事件并结束网页记录，不推断结束原因，不停止气动硬件。
6. 真实模型配置和发送字段授权应提前完成。结束后立即点击“分析当前窗口”；最晚不超过最后有效样本的 7 秒年龄门槛。保留输入连接，等待结果。不能把“结束后 7 秒”当作额外宽限：最后样本可能早于结束时刻。
7. 在专业端查看同一会话、展开固定输入和事件引用，填写备注，点击“已查看这份记录”或“需要补充记录”。回到用户端显示同一结果。增加新内容后会再次提示待复核。
8. 刷新或关闭前导出完整会话 JSON。需要肌电表格时另导出 CSV；CSV 不包含摄像头与 AI 历史。

## USB 接入与硬件边界

本轮系统枚举出现 Espressif `303a:1001`，仅是设备识别线索。**实际板型及板上固件未确认；本轮没有打开串口、烧录固件或操作气泵。** 可选遥测固件以 UNO A0/A5 接口为目标，不要据此直接套用到该枚举设备。

由硬件负责人先断开气泵外部电源，核对接线、板型、原固件和实际停止／泄压方式。USB 打开可能使部分板卡复位，因此只读网页也不能替代台架核验。保留可工作的原固件，关闭其他串口监视器，再由现场操作者选择对应端口。串口参数为 115200、8N1、只读。

| 输入／能力 | 当前含义 |
|---|---|
| 原协议每行一个数值 | 固件滤波肌电数值，非肌力百分比；A0 原始值、A5 均未上报 |
| 原协议阈值 66.0 | 源文件参考值，未从实际板卡回读 |
| 可选 v1 遥测 | 原始 ADC、滤波值、阈值、序号及 A5 标签；重复序号不算新样本 |
| A5 HIGH／LOW | 控制器输出电平；不代表已验证的充气、泄压或实际泵状态 |
| 压力、实际辅助力、泵反馈 | 未接入，保留 null／未测得 |
| AI／网页控制硬件 | 本轮未实现；没有新增串口写入或气泵命令 |

旧固件包含 4 秒与 1 秒阻塞等待，不能称为持续 500 Hz 肌电。旧程序达到阈值后 LOW 会跨越两段等待及执行开销，不能写成精确 4 秒充气。7 秒无有效完整帧或新样本时，页面隐藏实时值并结束网页记录。断开 USB、结束记录、关闭网页或服务器均不是物理急停。

## 摄像头与本地视频

`vision-vendor/` 随包提供 MediaPipe Tasks Vision 0.10.14、WASM 与 Pose Landmarker Lite 资源，加载来自本机服务，画面在浏览器本地处理。来源记录见 [vision-vendor/SOURCES.md](vision-vendor/SOURCES.md)。无需运行时从 CDN 获取模型。

摄像头输出的是**二维投影屈曲角估计**，以度为单位。记录保存左／右侧、采集时间、有效性、测量类型；未知侧别明确标记。摄像头与 USB 具有各自来源，不互相冒充。髋、膝、踝不可见时显示未测得；切换侧别产生独立事件。它不代表动作正确、临床关节角校准或助力效果。

本地视频始终标记为“录像回放 · 非实时”，记录另外保留媒体时间。页面不保存或导出视频帧。离开采集页会停止摄像头／视频观察，返回后需要重新开启。本轮本机浏览器已经加载本地模型并运行原有约 27 秒回放；该近景缺少完整髋、膝、踝，角度保持 null，未补假数。摄像头权限、实时画面和现场角度有效性仍需操作者另验，回放成功不代表摄像头实景或角度校准通过。

## 真实模型配置与外发授权

**本包当前未配置真实模型。** 页面显示“规则解释 / AI 未连接”是预期行为。不能把 Codex 登录当作应用凭证，也不要从其他目录寻找密钥。没有配置时仍可完成本地采集、复核与导出。

使用本版已加固的 `serve.py` 后，将 `.env.example` 复制为本项目根目录 `.env`，填入队伍已获授权的服务配置：

```dotenv
AIRFLOW_AI_ADAPTER=chat_completions
AIRFLOW_AI_BASE_URL=
AIRFLOW_AI_MODEL=
AIRFLOW_AI_AUTH_MODE=bearer
AIRFLOW_AI_API_KEY=
```

`BASE_URL` 填供应商文档明确的 API 基址，不包含 `/chat/completions`，不含查询参数或嵌入式账号密码。`MODEL` 必须是该账号实际可用的模型 ID。本适配器追加 `/chat/completions`，要求支持 `messages`、`response_format: {"type":"json_object"}`、非流式 `choices[0].message.content` 和 `finish_reason=stop`。不同协议的服务需单独适配，不能仅换地址假定兼容。接口参考：[Chat Completions 官方文档](https://developers.openai.com/api/reference/resources/chat)。

远端服务必须 HTTPS、`bearer` 和有效 key。明确运行本机无鉴权服务时，可配置 `AIRFLOW_AI_AUTH_MODE=local_no_auth`，地址仅允许 localhost／127.0.0.1／::1，key 留空。没有默认供应商、地址或模型；不会自动购买服务。

重启服务器后，页面检查完整服务地址与模型，展开“发送字段与授权范围”，由操作者勾选同意后手动分析。授权只保留在页面内存中，换来源、重连或配置变化需要重新确认。密钥仅在服务端；不放 URL、前端源码、浏览器存储、截图或日志。

手动请求仅发送以下白名单摘要：

- 请求、窗口、会话编号与 generation；来源、协议、窗口起止时间。
- 新样本数、样本及完整帧年龄、滤波最小／最大／均值、采样间隔。
- 阈值与来源、已上报 A5 标签和窗口内变化次数；`baseline=null`。
- 固定会话事件的类型、时间和编号：记录开始／结束、人工暂停／主动结束、复核请求。

**不发送摄像头画面、摄像头角度、事件自由文字、专业备注、姓名、联系方式、原始采样流或完整健康历史。** 撤销授权后不再发出新请求并丢弃待处理回复；已经送达服务商的摘要无法撤回。

分析范围为最近 60 秒内且属于当前会话的有效记录：至少 5 个新样本、跨度至少 4 秒、样本及帧年龄均不超过 7 秒。结束会话仅使用结束前的采样、阈值与 A5 事件，之后的新数据不会混入。工程门槛不属于医学标准；服务端 `GATES` 是配置源，页面同时显示。

请求间隔至少 10 秒，全服务并发 1 个，网络 I/O 超时 20 秒，浏览器 25 秒中止，无自动重试。模型失败不阻塞输入曲线。真实模型使用合成输入时同时显示“真实模型 + 合成输入”。

模型输出经过结构、数值证据、事件引用及内容约束校验；观察能定位到固定输入与相应事件。自然语言仍需人工核对。来源／会话变化、重连、过期或撤销授权使当前结果失效，晚回复留在原请求历史或标记丢弃，不迁入新会话。本轮输出只用于观察、记录完整性问题与复核，不生成设备命令。

## 会话与保存

统一会话包含 `sessionId`、独立来源、肌电点、摄像头观察、时间线、AI 请求／结果、物理反馈缺项和复核历史。专业端与用户端读取同一份对象，复核明确绑定内容版本；多个会话的备注草稿各自保存。

完整记录最多保留本页最近 40 个会话；单次肌电或角度观察各有 10000 条上限。历史 AI 面板保留最近 100 次请求。完整记录与专业备注在页面内存中；刷新后不能恢复。浏览器仅保存旧兼容格式的有限肌电摘要，它不能恢复完整会话，也不是跨设备同步。

- **完整会话 JSON：**肌电、独立角度观察、人工事件、固定 AI 输入／结果、来源及复核结果。
- **CSV：**每个新肌电采样一行，旧协议缺失字段留空，不复制 AI 结果到每个点。
- **AI 历史 JSON：**本页请求和结果，可见实际模型／规则失败／过期状态，不含密钥。

## 核验与排错

```bash
node --test tests/*.test.cjs
python3 tests/ai_backend_test.py
python3 tests/native_firmware_test.py
```

这些命令使用合成数据或测试替身，不会证明真实 USB、模型、摄像头或气动效果。浏览器验收及最终计数见 [TEST_REPORT.md](TEST_REPORT.md)。

| 现象 | 处理 |
|---|---|
| 端口已被占用 | 关闭串口监视器和其他占用页面；服务端口冲突则换本地服务端口 |
| 模型未配置 | 按本节填写队伍服务并重启；没有服务就继续明确标注的规则演示 |
| 结束后不能分析 | 最后记录样本已超过 7 秒；开始新会话采足数据并立即分析，不补造旧数据 |
| 摄像头拒绝或模型加载失败 | 检查浏览器权限、本地资源完整性；可选择明确标注的本地回放 |
| 原协议 A5 显示未上报 | 属于正确缺项，不可按阈值猜测气泵状态 |
| 专业端没有历史记录 | 必须是同一页面切换角色；刷新前导出，其他标签页不会同步 |

本轮重写前的说明已移入 [docs/archive-previous/](docs/archive-previous/)，仅供追溯。旧测试数量和旧开发状态不代表当前版本。
