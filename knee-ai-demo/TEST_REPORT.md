## 覆盖的关键场景

- legacy／v1 字段缺失、无效输入、重复序号、旧样本配新状态帧、来源断开与过期后隐藏实时值。
- 本会话窗口裁剪、有效样本与跨度门槛；结束后的阈值、A5 和 GPIO 不混入旧会话。
- 摄像头与回放独立来源；角度缺项、左右侧、单位、测量语义、遮挡及退化几何。
- 人工主动结束事件、统一导出、角色间同一会话、复核内容版本、各会话备注草稿隔离。
- 未授权／未配置不调用模型；失败明确进入规则状态；会话、来源、协议、重连、撤销、过期之后的晚回复不能污染新记录。
- 模型输出数值与固定输入匹配，事件引用只能来自本次请求，复核问题不能包含越界指令或未引用数字。
- 服务静态资源显式白名单、点文件／目录／私有日志与符号链接隔离、Host／Origin／CSRF 校验；密钥不进入前端或导出。

## 可重复运行的命令

```bash
node --test tests/*.test.cjs
python3 tests/ai_backend_test.py
python3 tests/native_firmware_test.py
```

浏览器工具仅用于验收，应用运行无须安装它们。本轮基础流程为采集→主动结束→未配置状态→专业复核→用户端确认，使用本地回放并核对来源。导出按钮已点击，完整 JSON 结构和来源经过 Node 测试，但浏览器下载文件落盘未独立验收。真实模型、实时摄像头、USB 与台架应分别补验后再进行完整实物彩排。

## 独立审查与修正

本轮独立审查发现并已在代码中增加相应修正与测试：

1. 结束会话分析曾混用后续快照的阈值和 A5；现在按会话已记录的采样及 GPIO 截取。
2. 摄像头记录曾丢失左右侧；现在保留并验证侧别、固定单位和测量类型。
3. 专业端切换会话曾残留备注；现在按会话隔离草稿，并保留同会话正在编辑的内容。

上述计数已核对本轮 final 输出文件，浏览器结果来自当前碳黑 × 钴蓝界面的三轮基础流程。审查发现的会话边界、角度侧别和备注隔离问题已修正，相关 Node 测试通过。后续如再修改相关代码，须更新对应证据。

## 验证结论的使用方式

软件通过只证明对应代码和测试条件；不得合并描述成“真实 AI、USB 和气动均已联通”。本地摄像头资源约 25 MB，MediaPipe 在浏览器内运行，画面与角度不外发；仍需现场核对真实摄像头权限和估计可用性。

真实模型成功应单独保留模式、模型、生成时间、固定输入、事件引用和结果；合成输入上的真实模型必须同时标明合成来源。真实 USB 成功应单独保留串口来源和接收证据；A5 电平不是实际压力反馈。台架与实物停止／泄压由硬件负责人另行记录。
