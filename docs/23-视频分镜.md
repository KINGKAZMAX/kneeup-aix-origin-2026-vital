# 附A · 录屏操作清单

## A1. OBS设置（macOS / Apple Silicon）
- 画布与输出均 **1920×1080**；帧率 **60fps**（图表滚动顺滑，慢放不糊）；编码器选Apple Silicon硬件H.264，质量CQP 18–20（或码率≥12Mbps）；音频48kHz，**麦克风与系统音分两轨**。
- 系统：外观分辨率选「更多空间」（1920×1080逻辑）→ 浏览器全屏（⌘⌃F）→ OBS「屏幕采集」；隐藏书签栏/桌面图标，开专注模式（防通知弹窗入镜）；OBS开3s录制倒计时。
- 浏览器按 doc24 规范 **1440×900 以上窗口跑demo**；开按键可视化插件或后期加点击涟漪，让观众看清"点了哪"。
- 场景集合建3个：①浏览器全屏（demo）②终端（git log）③数据卡/架构图页。用快捷键切，避免剪辑时对不上。

## A2. 录制顺序（每段单独录一个文件，宁多勿缺；录前先 `npm run demo:reset` 重置种子）
1. **T1 打卡→AI建议**：预填3/10→提交→等AI卡完整打出（含骨架屏）。
2. **T2_full 训练全程180s实时**：simulator自动脚本（种子`demo-90s`）+patient训练页双开，一条过——保底含62s黄/84s红原始时刻。**录完立即回放核对两个触发点已入镜。**
3. **T2_fast 快速档**：simulator切 `timeScale=3`（180s→60s）再录一条（黄≈00:21、红≈00:28），供正片主线使用。
4. **T3 医生端闭环**：列表红点→摘要→编辑器「AI建议调整」→预览下发→成功态；再切患者端补「今日计划已更新」横幅2s。
5. **T4 记忆锚点备镜**：模拟器手动模式把疲劳/腔压滑块拉爆→红灯三连（若S6素材不理想可用）。
