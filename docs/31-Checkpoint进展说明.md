## 三、遇到的技术难点

1. **旧固件不是连续采样**：原程序含 delay(4000)/delay(1000)，输出稀疏滤波值而非 500Hz 连续肌电波形。对策：协议层做状态帧序号去重，明确标注采样性质，不补点、不预测、不把它画成连续波形。
2. **A5 是控制器电平，不是物理反馈**：压力、实际助力、泵阀状态均无传感回读。对策：界面物理结果栏保持"未接入反馈"，控制电平不翻译成充气/泄压结论。
3. **姿态估计的诚实边界**：近景画面缺完整髋膝踝时无法构成有效角度。对策：角度保持 null 并标注缺失，回放视频始终带"回放"标签与媒体时间。
4. **AI 输出的可信度工程**：模型文本可能引用不存在的输入。对策：事件引用必须存在于本次固定输入（程序校验，不靠 prompt 约定）；新会话/来源变化/授权撤销后旧回复自动隔离；模型元数据由服务端设置。
5. **生理数据隐私**：默认不外发；首次启用外部模型需操作者确认发送字段；仅发送数值摘要与固定事件类型，不发送摄像头角度、画面或自由文本。
6. **多工具并行协作的一致性**：品牌定稿与仓库改名引发过链接连锁失效。对策：建立总控状态板单点收拢，所有入口以最终正典 slug 为准并自动巡检。
